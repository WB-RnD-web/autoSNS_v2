# SCP 원작 원문 팩

루틴 실행 환경에서는 SCP 위키 접속이 막혀 있어(EGRESS_BLOCKED) 원작 회차를 쓸 수 없었다.
그래서 원문을 여기 미리 받아 둔다. 루틴은 `git checkout origin/main -- scp/canon_pack` 으로 읽는다.

- 배정·받기: `pipeline/scp_canon.py` (`assign --date`, `fetch`, `list`)
- 라이선스: 각 파일의 본문은 SCP Wiki(https://scp-wiki.wikidot.com) 저작물이며 **CC BY-SA 3.0** 이다.
  파일 맨 위 `cite` 줄이 저작자 표기다. 원작 회차 영상 설명란에 그대로 넣는다(run_scp 가 자동으로도 붙인다).
- 원작 이미지는 받지 않았고 쓰지 않는다(이미지마다 라이선스가 다르다).
