# '2027 정미년 깊이 보기' 롱폼 글쓰기 안내 (루틴용)

왕별이 채널의 12~15분 롱폼 16편(2026-11-02부터 월·수·금 20:00 KST).
시청자는 거의 다 55세 이상 어르신이다. **말투는 다정한 조언, 자연스러운 우리말**로 쓴다.

루틴은 **글만 쓴다**. 아래는 코드가 정하고 검사한다. 못 넘으면 렌더도 업로드도 없다.

- 몇 번째 편인지, 공개 날짜, 장 순서와 장 제목
- 화면의 표, 출생연도 목록, 행운 색·숫자·방향
- 분량, 금지어, 살 조언 틀, 사실, 반복

```
python pipeline/longform_2027.py next      # 쓸 편 · 공개 시각 · 사실(JSON) · 빈 뼈대
python pipeline/longform_2027.py check <WRITE_TO 파일>
```

- 견본(= 실제 첫 편 E01): `docs/samples/longform_2027_E01.json`. 꼴과 말투를 참고하되 **문장을 옮겨 쓰면 검사에서 걸린다**.
- 사실 원본: `pipeline/longform_2027_catalog.json` (`next` 가 그 편 것만 보여 준다).

## 1. 구조

| 칸 | 무엇 | 화면 |
|---|---|---|
| `question` | 시청자가 할 법한 질문 한 문장. 끝은 `?` | 말풍선 큰 글씨(첫 화면) |
| `cold_open` | 인사 → 질문에 답하며 오늘 무엇을 풀지 | 질문 + 제목 + 띠 그림 |
| `chapters[]` | 코드가 정한 장 순서 그대로(뼈대의 `id`) | 장마다 꼴이 다르다 |
| `teaser` | **'다음 편'** 으로 다음 편 예고 | 다음 편 제목(코드) |
| `closing` | 선택. 짧은 마무리 인사 | |

코드가 붙이는 말:

- 첫 화면 끝: "목차는 설명란에 있으니 …"
- 첫 출생연도 장 맨 앞: 입춘 기준 줄
- 해마다: "68년생." (2000년대는 "2004년생.")
- Q&A마다: "첫 번째 질문이에요."
- 행운 장: 띠마다 색·숫자·방향 한 줄, 대장군·삼살 한 줄
- 맨 끝: '재미로' 고지와 구독 안내

이 말들은 루틴이 다시 쓰지 않는다.

### 장의 꼴(layout)과 쓰는 칸

| 꼴 | 쓰는 칸 | 화면 |
|---|---|---|
| `card` | `say` 2~5단락(단락 30~300자) + `points` 2~4줄(4~24자) | 요점이 단락마다 하나씩 켜진다 |
| `table` | `say` 1~4단락. 표를 짚어 준다 | 코드가 그린 표 — 12띠 신살 · 세 띠 좋은/조심할 달 · 한 띠 달력 · 사람(띠 사이) |
| `years` | `intro`(선택 0~200자) + 해마다 `say` 60~240자와 `point` 4~24자 | 출생연도 목록, 지금 해에 금색 막대 |
| `qa` | `qa` 2~4개: `q`(10~80자, `?`로 끝) · `a`(80~340자) · `point`(화면 답 요약 4~24자) | 질문 카드 → 답 카드 |
| `lucky` | `say` 1~4단락. 색·방향을 생활에서 쓰는 법 | 색 동그라미 · 숫자 · 방향 · 나침반 |

묶음 편(E01~E04)의 장:

1. 12띠 신살 표
2. 그 신살이란
3. ~5. 세 띠 출생연도별(띠마다 한 장)
6. ~8. 꼭 지킬(챙길) 것 셋
9. 좋은 달·조심할 달
10. 자주 묻는 질문
11. 행운

띠 단독 편(E05~E16)의 장:

1. 총운
2. 신살(·삼재) 잘 넘기는 법
3. 재물
4. 건강
5. 가정·자녀
6. 힘이 되는 띠
7. 좋은 달·조심할 달
8. 출생연도 ① 1930~60년대
9. 출생연도 ② 1970~2000년대
10. 자주 묻는 질문
11. 행운

### 쓰는 법

- **시작은 시청자의 질문으로** 연다. 예) "내년에 천살이 든다는데, 육십팔년생 원숭이띠인 저는 괜찮을까요?"
  `next` 의 '질문 씨앗'을 골라 쓰거나 바꿔 쓴다.
- **출생연도 줄은 해마다 다르게** 쓴다. 사실 JSON 의 `years[]` 를 쓴다.
  - `good`/`good_line`: 그 해 천간이 정(丁)에게서 받는 기운
  - `caution_line`: 챙길 것
  - `stem_note`: 정임합·정계충
  - `hwangap`: 67년생 = 환갑
  - 나이대에 맞는 생활 장면을 넣는다. 30~40년대생은 건강·자손, 50~60년대생은 은퇴·부모 봉양·손주, 70~2000년대생은 일터·결혼·진로.
  - **간지 이름을 말로 부르지 않는다.** 예를 들어 1956 병신생은 소리가 나쁘다.
- **Q&A는 실제로 궁금해할 것**을 고른다. 이사·계약·결혼 날·부부 띠·입춘 기준 같은 것이다. 답은 구체적인 조언으로 쓴다.
- **다음 편 예고는 '다음 편'으로**만 말한다. 영상은 몇 달 뒤에도 보이니 거의 늘 맞는 말로 쓴다.
  - 요일·날짜·'내일'·'이번 주'로 약속하지 않는다(검사가 막는다).
  - 마지막 편(E16)은 재생목록 안내로 맺는다.

## 2. 분량 — 12~15분

- **실측(2026-10-20, Spark Supertonic F2):** 앞 네 파트 1,773자, 무음을 잘라 낸 말 221.8초(원본 속도).
  - 분당 **480자** = 원본 속도.
  - 어르신용으로 0.92배 늦추고 조각·장 사이 쉼을 더하면 예상 4.3분, 렌더 결과도 4.3분이었다.
  - 검사는 분당 470자로 잰다(`LF27_CPM` 으로 바꾼다).
- **한 편 = 코드 문구 포함 약 4,900~6,100자(공백 포함).** 목표는 약 5,300자 ≈ 13분이다. `next` 가 그 편의 범위를 찍어 준다.
- 루틴이 쓰는 글은 약 4,800~5,500자. 코드 문구가 400~500자다.

대략의 배분:

| 부분 | 분량 |
|---|---|
| 시작 | 250~350자 |
| 카드 장 | 장마다 300~450자 |
| 출생연도 한 줄 | 80~130자 × 20줄쯤 |
| Q&A | 3개 × 220~300자 |
| 행운 | 150~250자 |
| 예고 | 100~180자 |

- 검사가 장마다 글자 수를 잰다. 카드 260~820자 · 표 200~700 · 행운 180~650 · Q&A 360~1,300, 출생연도는 줄 수 × 60~240.
- 전체 예상 길이가 12~15분 밖이면 고쳐서 다시 `check`.

## 3. 말(읽는 글)의 글자

- **한글·문장부호만 쓴다.**
  - 숫자는 한글로 쓴다: 세 가지 · 삼월 · **유월 · 시월** · 삼십 분.
  - 연도는 코드가 읽으니 줄 안에서 다시 말하지 않아도 된다. 꼭 말해야 하면 "육십구년 일월"처럼 쓴다.
- 영어·한자·이모지·해시태그는 쓰지 않는다. 화면 요점(`point`·`points`)에는 숫자를 써도 된다(예: "1월~2월 3일생은 앞 해 띠").
- 달은 **절기로 나눈 양력 달**이다. 삼월은 경칩부터 청명 전까지다. 사실 JSON 의 `month_spans` 에 날짜가 있다.

## 4. 살·삼재 낱말 — 조언 틀 안에서만 (사용자 10/20 "삼재 조언형 ㅇㅋ")

천살·화개살·반안살·월살·날삼재·대장군·삼살 같은 말은 **같은 문장 안에 조언이 있을 때만** 쓴다.
검사(`sal_frame`)는 문장마다 본다. 화면 한 줄과 제목은 통째로 본다.

- 통과:
  - "원숭이띠, 쥐띠, 용띠가 천살을 **잘 넘기는 법**을 짚어 볼게요."
  - "날삼재는 마무리를 잘하면 **복삼재로 바꿀** 수 있어요."
  - "천살의 해에는 몸을 **낮추고** 겸손하게 지내면 **좋아요**."
  - "올해 대장군이 동쪽이니 이사 방향은 **참고하세요**."
- 걸림(조언 틀 없음):
  - "올해는 삼재입니다."
  - "원숭이띠는 천살이 들었습니다."
  - 다른 문장의 조언은 이 문장을 덮지 않는다. 한 문장으로 이어 쓴다.
- 걸림(겁주는 말이 같이 있음 — 조언이 있어도 안 된다): 큰일 · 망한다 · 죽는다 · 재앙 · 흉하다 · 불길 · 액운 · 저주 · 사고가 · 최악.
- 시청자 질문(`question`, `qa[].q`)은 답이 조언이므로 겁주는 말만 본다.
  예) "천살이 든 해에는 이사를 미뤄야 하나요?"는 통과한다.

## 5. 쓰지 않는 것 (검사가 막는다)

- **겁주기:**
  - 큰일, 재앙, 망한다, 죽음·사망, 파산, 이혼, 사기·배신당함, 불행, 액운, 흉하다, 불길하다
- **한 해를 통째로 깎아내리기:**
  - 최악, 나쁜 해, 안 좋은 해, 힘든 한 해, 되는 일이 없다, 운이 없는 해, 불운
  - '조심' 띠도 꾸짖지 않는다. "서두르지 말고 차분히 가면 좋아요"처럼 조언으로 쓴다.
- **의료:**
  - 치료, 처방, 복용, 수술, 진단, 약 끊기, 병원 가지 말라, 영양제·보약·한약, 당뇨·고혈압·암
  - "건강 검진을 받아 보세요"·"물 자주 드세요"까지만 쓴다.
- **돈:**
  - 주식·코인·부동산·대출·빚내기·투자 권유, 로또·복권, 수익률·몇 배
  - "반드시 돈이 들어온다" 같은 단정도 쓰지 않는다.
- **무속 영업:** 부적, 굿, 천도재, 점집
- **자극·게임·젊은 말투:**
  - 충격, 대박, 무조건, 꿀팁, 레벨, 만렙, 레전드, 떡상, 티어, 등급표
  - 영문 등급(S급·에스급)
- **요일·날짜 약속:** 월요일~일요일, 내일, 모레, 이번 주, 다음 주, 매주, "저녁 여덟 시에"
- **사실과 다른 말:**
  - 띠 하나와 신살 하나가 같이 나오는 문장은 짝이 맞아야 한다(예: 쥐띠 = 천살).
  - 삼재 단계도 같다. 2027 날삼재는 돼지·토끼·양뿐이다.
  - 호랑이·말·개는 2028 들삼재라 "내년"으로만 말한다.
  - 사실 JSON 에 없는 신살·띠 관계를 지어내지 않는다.
- **복사:**
  - 같은 대본 안에서 단락끼리, 지난 편·견본과 거의 같은 단락(글자쌍 자카드 0.6 이상)은 쓰지 않는다.
  - 출생연도 줄은 특히 해마다 다르게 쓴다.

## 6. 사실 메모 (2027 정미년 — 코드 계산, 재미로 보는 운세)

- 2027년 = 정미(丁未)년. 정 = 불, 미 = 흙(양띠 해).
- 입춘은 2027-02-04 10:46. 띠는 입춘 기준이라, 양력 1월 1일~2월 3일생은 앞 해 띠다.
- 십이신살은 삼합 그룹의 지살부터 센다.
  - 신자진(원숭이·쥐·용) = **천살**
  - 해묘미(돼지·토끼·양) = **화개살 + 날삼재**(2025 들 · 2026 눌 · 2027 날)
  - 인오술(호랑이·말·개) = **반안살**(2028~2030 삼재)
  - 사유축(뱀·닭·소) = **월살**
- 대장군 **동쪽** · 삼살 **서쪽**. 이사·큰 공사 방향을 잡을 때 참고만 하라고 말한다.
- 未와의 관계:
  - 말 = 육합
  - 돼지·토끼 = 삼합
  - 양 = 같은 띠(본명년 · 67년생 환갑)
  - 소 = 충·형
  - 쥐 = 원진·해
  - 개 = 형·파
  - 호랑이·용·뱀·원숭이·닭 = 직접 관계 없음
- 좋은 달·조심할 달, 행운 색·숫자·방향, 건강은 쇼츠 '2027 신년운세' 표와 같은 계산이다. 화면과 말이 어긋나지 않게 JSON 그대로 쓴다.
