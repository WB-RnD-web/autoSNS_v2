# 진행자 이미지 (별이·별하)

쇼츠 화면 아래 앵커 데스크에 앉는 채널 캐릭터. `motion_short.py` 가 이 폴더의 두 파일을 쓴다.

| 파일 | 캐릭터 | 목소리 |
|---|---|---|
| `byeori.png` | 별이 (남) | `VO_VOICE_BYEORI` (기본 ko-KR-HyunsuMultilingualNeural) |
| `byeolha.png` | 별하 (여) | `VO_VOICE` (기본 ko-KR-SunHiNeural) |

- 둘 중 하나라도 없으면 진행자 없이 기존 화면으로 렌더한다.
- 끄기: 레포 변수 `PRESENTER=0` · 별하 혼자 말하기: `PRESENTER_DUO=0`

## 지금 파일 (v0, 2026-09-27)

`characters/refs/왕별이 뉴스데스크.png` 에서 GrabCut 으로 오려낸 것. 원본이 768px 폭이라 해상도가 낮고
(가로 265~291px), 표정이 하나뿐이다.

## 교체 규격 (DGX 에서 새로 만들 때)

- 투명 배경 PNG, 상반신(책상 위로 보이는 만큼), 정면, 아래쪽이 책상 선에서 잘린 모양
- 세로 1000px 이상 권장 — 화면에서 약 430px 높이로 줄여 쓴다
- 두 캐릭터가 같은 그림체·같은 조명·같은 크기 비율
- 파일명을 그대로 두고 덮어쓰면 코드 수정 없이 바뀐다
