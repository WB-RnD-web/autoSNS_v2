# 인스타 릴스 — 한 편 쓰는 법

계정: **0원으로 AI 유튜브 채널을 굴리는 실제 기록**(한국어). 두 유튜브 채널 — 한국어 **왕별이**, 영어 **Nine Tails Tales** —
을 클로드 루틴·GitHub Actions·사내 GPU 서버로 굴리면서 **실제로 겪고 잰 것**을 따라 할 수 있는 가이드로 만든다.
홍보 계정이 아니다: 퍼지는 건 "저장해 두고 그대로 따라 하세요"형 가이드이고, 자기 홍보형은 조회가 1/10로 떨어진다.

코드가 강제하는 것(`python insta/insta.py check <파일>` 이 ✅ 여야 렌더·게시된다): 요일·주제·분량·숫자·금지 표현·해시태그.
이 문서는 **좋게** 쓰는 법이다.

## 무엇을 쓰나 — 고르지 않는다
`python insta/insta.py next --date <오늘, KST, YYYY-MM-DD>` 가 알려 주는 것 **하나만** 쓴다.
- `post: false` → 오늘은 올리지 않는 날. 아무것도 커밋하지 않고 끝.
- `format: guide`(월·수·금) → `topic` 의 `facts` 가 뼈대, `careful` 은 반드시 지킨다, `nums` 가 쓸 수 있는 숫자 전부.
- `format: report`(일) → 주간 성적표. `recent_changes`(그 주에 합쳐진 PR 제목)에서 "이번 주 바꾼 것"을 고른다. 지어내지 않는다.
- 견본: 가이드 `insta/samples/first-second.json`, 성적표 `insta/samples/weekly-report.json` — 먼저 읽고 목소리·길이·모양을 맞춘다.

## 숫자 — 직접 쓰지 않는다 ★
말·제목·화면 글자·캡션에 **아라비아 숫자를 쓰면 검사기가 거절한다**. `천 회`·`두 배`처럼 한글로 쓴 숫자 주장도 거절한다.
숫자는 전부 자리표시자로 — 렌더할 때 코드가 실측값을 넣고, 말로는 한글 읽기로 바꿔 읽힌다.
- `{{fact.<key>}}` — 그 주제의 `nums`(과 공통 `nums`). 화면엔 `1,285회`, 말로는 "천이백팔십오 회".
- `{{wb.subs}}` `{{ntt.week.views}}` 등 — 렌더 때 YouTube API 로 채우는 현재 값. `next` 의 `placeholders` 목록에 있는 것만.
- `{{vid.<key>.views}}` — 그 영상의 지금 공개 조회수.
- 값에는 **단위가 붙어 나온다**(`194명`, `1,285회`, `20편`) → 단위를 또 쓰지 말고, 조사는 단위에 맞춘다
  (`{{wb.week.uploads}}을`, `{{wb.week.views}}가`, `{{fact.continued}}뿐`).
- 작은 개수는 한글로 써도 된다: "세 가지", "두 번", "열두 띠". 주장하는 숫자(조회·시간·배수·금액)는 반드시 자리표시자.
- 캡션의 단계 번호(`1.` `2.` …)는 괜찮다.

## 목소리
- **해요체**, 담백하게, 1인칭("제 채널", "저는"). 과장·감탄사·유행어 없이. 전문 용어는 한 번 풀어 준다
  ("'계속 시청함', 그러니까 넘기지 않고 본 비율").
- **정직**: 잘 안 된 것도 숫자 그대로. 원인을 모르면 "원인은 아직 몰라요". 하루 비교는 "하루 비교라 단정은 못 해요".
  `careful` 에 적힌 것은 빠뜨리지 않는다.
- 금지(검사기가 막는다): 돈 주장(부업·"한 달 만에 벌었다"), 과장(대박·충격·무조건·떡상), 참여 낚시("댓글 남기면 보내 드려요"),
  구독·팔로우 요청, 링크·@핸들. 채널 안내는 코드가 캡션 마지막 줄에 붙인다.
- 가이드는 몇 달 뒤에 저장해 보고 따라 하는 콘텐츠다: "오늘·요즘·최근·이번 주·올해" 금지. 날짜가 필요하면 `{{fact.…}}` 절대 날짜.

## 구조(가이드) — 30~45초, 장면 6~8개
1. **첫 장면 = 결과·숫자 한 줄**(인사 없이, 45자 이하). 첫 프레임 화면도 가장 센 것(숫자 비교 `vs`·`stat`, 또는 실제 썸네일).
2. 무슨 일이 있었나 — 실제 화면(썸네일·말풍선·흐름도)으로 1~2장면.
3. 왜 그런가 / 무엇을 바꿨나 — 1~2장면. 추정이면 추정이라고.
4. **따라 하는 법** — `steps` 로 3~4단계(한 장면에 하나씩 `hi` 로 짚거나, 마지막에 전부).
5. **마지막 장면**: 한 줄 요약 + "저장해 두고 그대로 따라 해 보세요"(검사기가 '저장'을 본다). 화면은 단계 전체(`"hi": -1`) — 저장할 이유.
- 한 장면 말은 20~60자. 전체 말은 검사기 기준 150~230자(공백·문장부호 빼고 읽는 글자).

## 구조(성적표, 일요일)
두 채널 숫자를 `week` 화면으로 먼저 → 가장 많이 본 영상(`thumb: wb.week.top`) → 영어 채널 → 이번 주 바꾼 것(`steps`, recent_changes 에서)
→ 구독자와 다음 주 한 줄. 잘 안 된 주도 그대로. 두 채널 숫자가 다 있어야 통과한다.

## 제목(위 두 줄) — `headline`
- 1~2줄, 한 줄 한글 12자 안쪽. **첫 프레임부터 끝까지** 화면 위에 고정된다 — 소리 없이 넘기며 봐도 무슨 영상인지 알 수 있게.
- 1줄: 상황/주제, 2줄(노란색): 결과·숫자. 예: `["첫 화면이 가른 차이", "{{fact.continued}} vs {{fact.card_continued}}"]`
- catalog 의 `headline` 을 그대로 쓰거나 더 낫게.

## 화면(`show`) — 장면마다 하나, 전부 코드가 데이터로 그린다
| 종류 | 쓸 때 |
|---|---|
| `{"vs": [{"label","value","tone":"bad"},{…,"tone":"good"}]}` | 전·후, 두 영상 비교 — 첫 장면에 좋다 |
| `{"stat": "{{fact.x}}", "label": "…", "tone": "good\|bad\|neutral"}` | 숫자 하나를 크게 |
| `{"bars": [{"label","value"}, …], "hi": 0}` | 2~6개 비교(같은 단위끼리만) |
| `{"thumb": "<videos 키>", "label": "…"}` | 실제 유튜브 썸네일(공개 영상만). 성적표는 `wb.week.top`·`ntt.week.top` |
| `{"steps": ["…"], "hi": 0}` | 따라 할 단계(16칸 안쪽 한 줄씩). `hi: -1` = 전부 체크 |
| `{"flow": ["…"]}` | 구조·순서(2~5칸, 칸마다 12자 안쪽) |
| `{"chat": [{"who":"me","text":"…"},{"who":"ai","text":"…"}]}` | 지시 vs 실제 결과 같은 장면(말풍선 40자 이하) |
| `{"text": "…", "sub": "…"}` | 핵심 한 문장 |
| `{"img": "영어 한 문장"}` | 분위기 그림(Spark). **글자·화면·차트·노트북·폰이 들어가는 그림 금지**(검사기가 막는다) — 숫자·화면은 위 카드로 |
| `{"gumi": "front\|bead\|wink"}` | 영어 채널 이야기에서 구미 초상 |
| `{"week": "both\|wb\|ntt"}` | 성적표 카드(숫자는 전부 stats) |
- 가이드는 화면 종류를 두 가지 이상 섞고, 숫자 화면(`vs`·`stat`·`bars`·`thumb`·`week`)을 하나 이상.
- **스크린샷·터미널·설정 화면·토큰·이메일은 어떤 형태로도 넣지 않는다.** 코드 조각도 넣지 않는다.

## 캡션 — 캡션이 매뉴얼이다
```
첫 줄: 결과 한 줄(45자 이하 — '더 보기' 전에 보이는 부분)

무슨 일이었나 2~3줄(• 로 시작해도 좋다)

따라 하는 법 제목
1. …
2. …
3. …

저장해 두고 ○○할 때 그대로 해 보세요.
(필요하면) 정직한 한 줄: 비교의 한계·지표 뜻
```
- 단계 3줄 이상(`1.` 형식), '저장' 줄 필수, `#` 금지(해시태그는 `hashtags` 에), 링크·@ 금지. 1,800자 이하.
- 끝에 코드가 채널 안내·AI 표시·해시태그를 붙인다 — 직접 쓰지 않는다.

## 해시태그 — 분류용 3~5개
주제어 중심: `#유튜브쇼츠` `#유튜브팁` `#AI유튜브` `#클로드` `#AI자동화` `#유튜브운영` … 같은 태그만 반복하지 말고 주제에 맞게.

## 끝
`output/insta/<date>_<slug>.json`(`next` 의 `file`)로 저장 → `python insta/insta.py check <파일>` 이 ✅ 가 될 때까지 고친다
→ **그 파일 하나만** 커밋 → `routine/insta` 에 push.
