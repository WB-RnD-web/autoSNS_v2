# 인스타 sci(도파민 과학) — 대본 쓰는 법

심해·우주·극한 생존을 **진짜 숫자로** 보여 주는 20~40초 릴스예요. 시험 기간은 10/15~10/28(하루 한 편).
보는 사람이 첫 1초에 "어? 몇 분?" 하고 멈추고, 숫자가 터질 때마다 끝까지 보게 만드는 게 목표예요.
골라보기가 아니라서 회차 번호(`오늘의 골라보기 #N`)는 없어요.

## 순서
1. `python insta/pick_plan.py next` 가 `kind: sci` 를 주면 이 문서를 따라요. 편(slot)·항목(`src_n`)은 코드가 정해요 — 바꾸지 않아요.
   `due: false`·`already_written: true` 면 아무것도 하지 않고 끝내요.
2. `entry` = 영어 쇼츠 `gumiho/tales/shorts_catalog.json` 의 그 항목이에요. **숫자는 `entry.facts` 에서만** 가져와요.
   `beat_ideas`·`items_idea` 는 순서·장면 참고, `careful` 은 꼭 지켜요(단정 금지·'약' 붙이기 등).
3. 견본 `insta/samples/sci_mariana.json` 과 같은 모양으로 `file` 이름 그대로 써요.
4. `python insta/pick_reel.py check <파일>` 이 ✅ 가 될 때까지 고쳐요.

## 모양
| 필드 | 규칙 |
|---|---|
| `date`·`kind: "sci"`·`src_n`·`slug` | `src_n` 은 `next` 의 `src_n` 그대로(다르면 막혀요) · `slug` 영어 소문자·하이픈 |
| `hook` | 두 줄, 줄마다 14자 이내. 예: `["마리아나 해구 바닥", "몇 분 버틸까?"]` — 영상 내내 위에 떠요 |
| `say_intro` | 50자 이내, **첫 문장이 바로 질문**이고 `?` 로 끝나요. 인사·소개 없이 |
| `beats` | 4~6개. `big` 큰 숫자(12자) · `sub` 설명(24자) · `say` 말(45자) · `img` 영어 실사 그림 · `src` = `sources` 번호 |
| `verdict` | `big` 12자(예: `생존 확률 0%`, `1위 거대관해파리`) · `say` 40자 |
| `caption` | 한 줄 — 훅 + 이모지 하나. 출처·질문·해시태그는 코드가 붙여요 |
| `hashtags` | 5개까지 · `sources` 는 entry 것을 **그대로 복사** · `bench.format` 필수 |

compare(크기·속도 순위) 항목은 박자를 **작은 것 → 큰 것** 순서로 쓰고, 박자마다 `value`(entry 의 `unit` 단위 숫자 — `items_idea` 값)를 넣어요.
코드가 그 값으로 로그 막대를 그려요. 예: `{"big": "12cm", "sub": "심해아귀 암컷", "say": "…", "img": "…", "src": 0, "value": 0.12}`

## 숫자 — 지어내지 않아요
- 화면·말·캡션의 **모든 숫자는 그 항목 facts 에 있는 수**여야 해요(콤마·단위는 안 봐요: `10,935m` = facts 의 `10,935 meters`).
  `430만`·`54억` 처럼 만·억으로 쓰면 facts 의 `4.3 million`·`5.4 billion` 과 맞춰 봐요. 판정의 확률(`0%`)·순위(`1위`)만 예외예요.
- facts 에 없는 비교(에베레스트·냉장고·버스 몇 대…)·시간(몇 초 만에)은 쓰지 않아요. 출처가 시간을 안 주면 시간을 말하지 않아요.
- 분수는 `1/1,000`(화면) · `1,000분의 1`(말). `CO2` 대신 `이산화탄소`, 영하는 `영하 108도`처럼.

## 말투·금지
- 짧고 세게, 해요체. 한 박자 = 숫자 하나 + 한 문장. "여긴 완전한 어둠이에요." 같은 감각 한 줄은 좋아요.
- **부탁 금지**: 댓글·저장·공유·팔로우·"끝까지 봐 줘" 같은 말은 쓰지 않아요. 끝은 코드가 열린 질문을 붙여요
  (생존 `너라면 몇 초 버틸 것 같아요?` · 비교 `제일 놀라운 건 뭐였어요?`).
- **잔혹 묘사 금지**: 피·시신·터진다·찢긴다 같은 말 없이, 숫자와 환경으로만 무섭게.
- **실제 희생자·실존 인물 금지**(잠수한 사람·사고 이름 X) · **영화·만화 이름 금지**(타이타닉·쥬라기 공원 X).
- `img` 는 영어로, 어두운 실사 장면만: **사람 얼굴 클로즈업·글자·표지판·로고가 없는 장면**("plain dark water"처럼 긍정형으로 써요 —
  `text`·`label`·`face` 같은 낱말은 check 가 막아요). 화풍(어두운 실사·세로)은 코드가 entry `look` 으로 붙여요.
