# 인스타 '오늘의 골라보기' — 대본 쓰는 법

계정 목표는 **인스타 팔로워를 키우는 것 하나**예요. 유튜브 채널 홍보는 하지 않아요(링크·채널 이름·"유튜브에서" 금지).
보는 사람이 **멈춰서 하나 고르고, 끝까지 보고, 다시 보는** 20초 안팎 릴스예요.
**10/13부터 하루 두 편** — 낮 편(a, 12시대)·저녁 편(b, 7~8시대). 어느 편·어떤 꼴인지는 코드가 정해요.
**10/15~10/28 sci 시험** — 날마다 두 편 중 한 편은 **sci(도파민 과학: 심해·우주·극한 생존)**, 다른 한 편이 골라보기예요
(sci 는 저녁·낮을 날마다 번갈아요). `next` 가 `kind: sci` 를 주면 이 문서 말고 **`insta/SCI_WRITING.md`** 를 따라요
(`writing`·`exemplar`·`entry` 그대로). 골라보기 꼴 순서는 sci 를 건너뛰고 그대로 이어져요.

## 순서
1. `python insta/pick_plan.py next` — 지금 차례인 **편(slot)** 과 **꼴(kind)** 은 코드가 정해요(16시 전이면 낮 편). 바꾸지 않아요.
   `due: false` 면 지금은 쓸 차례가 아니에요. `already_written: true` 면 그 편은 이미 썼어요. 둘 다 아무것도 하지 않고 끝내요.
   파일 이름은 `file` 그대로 써요 — 한 번에 한 편만 써요.
2. 서칭(로컬 크롬, 하루 10건 안쪽): `keywords` 로 인스타 검색 상위 릴스를 보고, **요즘(최근 30일)** 잘 된 것 1~3개를 골라요.
   빌리는 건 **꼴·주제 방향·첫 장면 문구 구조**뿐이에요. 그림·문구·질문은 새로 만들어요.
   본 것은 `bench.seen` 에 "계정 · 무엇 · 조회수"로 적어요(지어내지 않아요 — 못 봤으면 비워 두고 `bench.format` 만).
3. `exemplar`(견본)와 똑같은 모양으로 `output/insta_pick/<날짜>_<kind>_<slug>.json` 을 써요. `slug` 는 영어 소문자·하이픈.
4. `python insta/pick_reel.py check <파일>` 이 ✅ 가 될 때까지 고쳐요.
5. `recent` 에 있는 주제·문제와 겹치지 않게 해요(같은 문제·같은 고르기 소재 금지).

## 꼴마다
| kind | 무엇 | 꼭 지킬 것 |
|---|---|---|
| pick | 그림 넷 중 하나 → 번호별 결과 | 소재 4개는 한눈에 달라 보이게(색·모양). 결과는 따뜻하고 구체적인 한 줄 행동 |
| card | 뒤집힌 카드 넷 → 앞면 그림과 메시지 | `img` = 카드 뒷면(색·무늬만 다르게), `reveal_img` = 앞면 상징 그림(글자 없는 장면) |
| quiz | 상식 문제 2~3개, 3초 뒤 정답 | **사실만**. 헷갈리는 것·논쟁 있는 것·숫자가 출처마다 다른 것은 빼요. `say_a` 에 정답 낱말이 그대로 들어가요 |
| balance | 둘 중 하나 세 판 | 둘 다 고르기 아까운 짝. 누구를 깎아내리는 질문·위험한 질문 금지 |
| birth | 태어난 달 12칸 표 | 칸마다 14자 안쪽, 12칸이 서로 다르게. 재미로 보는 것 — 단정·겁주기 금지 |

## 말투·금지
- 해요체, 짧게, 다정하게. 2030 이 친구에게 보내고 싶은 말.
- 그림 묘사(`img`·`reveal_img`·`bg`)는 영어로, **사람 얼굴·실존 인물·브랜드·글자 없는 장면**으로 써요("no text" 같은 부정형 대신
  "plain background", "simple scene" 같은 긍정형).
- 금지: 의료·투자·로또·겁주기·저주, '팔로우하면'·'링크'·DM 유도, "댓글에 OO 쓰면 복이 와요" 같은 미끼, 남의 계정·영상 언급.
- ★부탁 금지(10/11): 화면 글·목소리(`say_*`·`outro_text`·결과·문제)에 **댓글·남겨 줘·보내 줘·공유해·태그해·저장해** 를 쓰지 않아요.
  인스타는 참여를 대놓고 부탁하는 글(예: "숫자로 댓글 달아 줘")을 추천하지 않아요. 끝은 **열린 질문**으로("너는 어느 쪽이었어요?").
  `check` 가 막아요.
- 캡션(`caption`): **한 줄만** — 고르라는 말 + 이모지 하나. 본문에 `#` 를 쓰지 않아요.
- 해시태그(`hashtags`): **5개까지**(인스타 2025-12-18부터 5개 제한 · 검색에만 돕고 도달은 안 늘려요). 넘으면 앞 5개만 써요.

## 코드가 붙이는 것 — 쓰지 마세요 (10/9)
`pick_reel.py` 가 캡션과 커버에 **알아서** 붙여요. 대본 `caption` 에 같은 말을 쓰면 그 줄은 빠지고, `check` 가 ⚠️ 로 알려요.
1. **회차** — 캡션 첫 줄 앞 `오늘의 골라보기 #N` (10/8 = #1, 골라보기 편마다 하나씩 — 10/13 낮 = #6 · sci 편은 세지 않아요) · 커버에도 작은 라벨로.
2. **열린 질문 한 줄**(10/11) — pick `어떤 그림이 제일 끌렸어요?` · card `어떤 카드가 제일 끌렸어요?`
   · quiz `제일 헷갈렸던 문제는 뭐였어요?` · balance `제일 고르기 어려웠던 판은 뭐였어요?` · birth `내 달 풀이, 맞는 것 같아요?`
   (10/9 의 '친구한테 보내서 물어봐요'·'숫자만 댓글로'는 뺐어요 — 인스타 2024-06-02: 특정 단어·숫자로 댓글을 부탁하면 추천에서 빠져요)
3. **해시태그 5개 자르기.**

그래서 `caption` 에는 **댓글·보내기·친구·공유·태그 같은 말, 회차 번호를 쓰지 않아요.**

## 쓰레드 — 따로 쓰지 않아요 (2주 시험 10/11~10/24)
그날 **골라보기 편 하나**를 코드(`insta/pick_threads.py`)가 쓰레드 글 하나 + 내 답글 하나로 옮겨요. 작가가 더 쓸 것은 없어요.
sci 날(10/15~)은 sci 가 아닌 골라보기 편(낮이든 저녁이든), 골라보기가 두 편인 날은 저녁 편이에요. **sci 는 쓰레드에 안 가요.**
- 끝맺음은 코드가 반말로 바꿔요(`골라 봐요` → `골라 봐`). 그래서 `headline`·`result`·`lines`·`q`·`why` 는 **해요체로 끝내요**.
- 결과·문제·해설에 `댓글`·`유튜브`·`#` 를 쓰지 않아요 — 그날 쓰레드가 막혀요.
- `hashtags` **첫 개**가 쓰레드 주제 태그(하나)가 돼요 — 꼴을 가장 잘 말하는 것을 맨 앞에 둬요.
- 퀴즈 `choices`·밸런스 `label` 은 쓰레드 투표 보기가 돼요(25자 안 — 지금 규칙 12자면 충분해요).
