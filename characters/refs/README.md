# 캐릭터 고정 이미지 (무료 영상용)

여기에 **별이·별하 이미지**를 넣으면, 매일 영상을 만들 때 **이 이미지를 그대로 사용**해요.
(매번 AI가 새로 그리지 않으므로 **캐릭터가 항상 동일**하고, 무료에 항상 동작합니다.)

## 넣는 법 (가장 중요한 1개)
- `twoshot.png` — **별이·별하가 함께 앉아 있는 앵커 투샷** (이게 메인. 앵커 컷에 사용)

## 선택(있으면 더 좋음)
- `still.png` — 토픽(뉴스 내용) 배경용 이미지. 없으면 `twoshot`을 재사용합니다.
- `byeori.png` / `byeolha.png` — 개별 이미지(참고용/확장용)

> JPG/WebP도 가능합니다. 파일명이 위와 달라도, 이미지가 1장이라도 있으면
> `generate_images.py`가 알아서 앵커 컷에 사용합니다(투샷류를 우선 선택).

## 동작 방식
`pipeline/generate_images.py` 가 기본(`IMAGE_BACKEND=static`)으로 이 폴더의 이미지를
`output/assets/<날짜>_twoshot.*` 등으로 복사 → ffmpeg가 자막·켄번스를 입혀 영상화합니다.

(나중에 유료 결제 후 AI 생성으로 바꾸려면 저장소 변수 `IMAGE_BACKEND=gemini` 로 전환)
