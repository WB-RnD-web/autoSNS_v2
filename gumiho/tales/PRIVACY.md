# Nine Tails Tales uploader — Privacy Policy

_Last updated: 2026-09-29_

**Nine Tails Tales uploader** is a private automation tool used only by the owner of the YouTube channel
[Nine Tails Tales](https://www.youtube.com/@NineTailsTales). It is not offered to the public.

## What it does
- Uploads videos, thumbnails and captions that the channel owner produced to the owner's **own** YouTube channel,
  and adds them to the owner's playlists, using the YouTube Data API.

## What data it accesses
- Only the channel owner's own YouTube account, with the owner's explicit OAuth consent.
- It does not access, collect or store data about any other Google user or YouTube viewer.

## Storage and sharing
- The OAuth token is stored as an encrypted secret in this repository's GitHub Actions settings and is used
  only to perform the uploads described above.
- No data is sold, shared with third parties, or used for advertising.
- The owner can revoke access at any time at https://myaccount.google.com/permissions .
